# Menu images

The links below are **Pinterest share links** (`pin.it/…`). They redirect to a
Pinterest *page*, not an image file, so they can't be used directly in `<img src>`.

To use real photos, do one of:

1. **Direct image URL** — open each pin, right-click the image → "Copy image
   address" (must end in `.jpg` / `.png` / `.webp`), then in the admin panel
   (`/admin/menu` → edit a dish → Image URL) paste it. Falls back to the SVG
   placeholder automatically if a URL breaks.
2. **Local files** — drop images in `public/food/` and set Image URL to
   `/food/<file>.jpg`.

Until then every dish shows its deterministic warm SVG placeholder.
